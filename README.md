# Gate Repairs Pretoria

Static four-page website for Gate Repairs Pretoria.

## Files

- `index.html` — home page
- `about.html` — company story and proof
- `services.html` — services, pricing tables and FAQs
- `contact.html` — contact methods and service areas
- `styles.css` — shared responsive styling
- `script.js` — active navigation, mobile-menu cleanup and footer year
- `images/` — local website images

Open `index.html` directly in a browser or upload the folder to any static web host.
